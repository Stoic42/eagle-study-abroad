## 路径 A：留学（5 条候选）

### A1 🇺🇸 美国 Need-blind 全奖（理论最优，门槛最高）

**机制**：仅 10 所美国顶尖私立大学对国际生执行 Need-blind + 100% 满足需求政策：
- 哈佛 / 耶鲁 / 普林斯顿 / MIT / 达特茅斯 / 布朗 / 圣母 / 阿默斯特 / 鲍登 / 华盛顿与李
- **国际生名额极少**：每年全球不足百人录取，大部分家庭年收入 < 6 万美元
- 耶鲁 2026 新政：家庭年收入 < 20 万美元免全部学费，< 10 万美元覆盖所有食宿

**Eagle 匹配度**：
- ✅ 家庭收入：修自行车 → 推断 < 6 万美元 = **完美符合**
- ✅ 课外亮眼：WAIC 华为 / Ignition / SheNicest 联合创始人 → **远超普通申请者**
- ❌ 硬学术门槛：未加权 GPA 3.9+ / SAT 1530+ / 托福 108+（**Eagle 雅思 5 = 托福 60-65 区间，远低于 108**）
- ❌ 时间窗口：Eagle 高二启动 → 高三 11 月早申 = **9 个月要把英语 + 学术冲到顶端 → 极难**

**结论**：理论上最优，但 9 个月内把雅思 5→7.5 + GPA 冲到 3.9+ 极难。**除非 Eagle 愿意 gap year**（高考后全职准备 1 年再申请），否则不建议作为主路线。

### A2 🇺🇸 美国 Merit 奖学金 + 公立旗舰（性价比可达）

**机制**：Merit 奖学金 = 学术/竞赛/领导力获奖，**不需披露家庭财务**
- 公立旗舰（UC 系 / UW-Madison / UIUC）对国际生 Merit 名额扩招
- UC 系统 2026 国际生 Merit 名额扩至 4000 名
- **可叠加**：60% 院校支持 Need-based + Merit 叠加（如杜克）

**典型录取画像**（成功案例参考）：
- Z 同学（普高 AP / GPA 3.9+ / TOEFL 100+ / USACO Gold / AIME 晋级 / Physics Bowl 银奖）→ **UIUC / NYU / UCD / UCI / UCSB / UW-Madison CS**
- 李明（北京普高 / GPA 3.2 / 托福 90 / USACO 奖）→ **UCD CS**（强调开源 + 编程兴趣小组领导力）
- L 同学（北京国际部 / GPA 3.8+ / 托福 110+ / ACT 33+ / 物理竞赛 / 辩论社）→ **UCB / UCLA / Rice / GIT**
- 王同学（天津某中学 / 托福 100+ / SAT 1450+ / 5 门 AP / AMC12+AIME / CTB / LIBF）→ **UIUC / UCD / UCSB / OSU / UW Seattle**

**Eagle 匹配度**：
- ✅ 课外亮眼（WAIC / SheNicest / Ignition）= **软背景强于上述所有案例**
- ❌ 校内 GPA 3.9+ → **Eagle 普高成绩一般是个挑战**（普高 GPA 难冲高分，且不参与排名）
